クラスを貼るだけでヴァンサバ的な「宝箱が開いた瞬間」の快感を出す、小さなCSS/JSフレームワーク。 .dopa を付けた要素をクリックすると、パーティクル・画面フラッシュ・シェイク・ポップアップ文字がまとめて発火する。

クリックしてみて <button class="dopa dopa-max">OPEN</button>

リファレンス
.dopa
必須の起点クラス。クリックで演出が発火する。
.dopa-sm / md / lg / max
強度（既定 md）。パーティクル数・画面フラッシュの強さ・シェイク幅を変える。
.dopa-common / rare / epic / legendary
色テーマ（既定 legendary）。ゲームのレアリティ配色に合わせてある。
data-dopa-text="..."
ポップアップする文字を上書きする。未指定なら強度ごとの既定文言（+1 / GET! / NICE! / LEGENDARY GET!!）。
dopa:trigger
クリック時に発火する CustomEvent。detail に {size, rarity} が入るので、効果音を鳴らすフックなどに使える。
prefers-reduced-motion
縮小モーションを希望する環境では、パーティクル・シェイク・フラッシュを自動でスキップする。

実運用では dopa.css と dopa.js をそのまま自分のプロジェクトに置くだけ。このページはその2ファイルをそのまま読み込んで動いている。

DOPAStrap — a tiny CSS/JS framework for game-juice UI feedback.
